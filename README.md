# Demo（静态原型 · 零依赖）

快速看效果用的高保真静态原型。**没有框架、没有构建、没有 npm 依赖**，直接用浏览器打开即可，所有 token 与 `docs/design/DESIGN_SYSTEM v1.md` 对齐，后续可整体搬进 Next.js + Tailwind。

## 怎么看

直接双击打开（推荐 Chrome / Edge，文件协议 `file://` 下 localStorage 正常工作）：

```
web-app/demo/index.html     ← 内容发现首页（7 段完整骨架）
web-app/demo/create.html    ← 创造转化：创作参考板 + 方案与脚本
```

也可以起个本地服务（可选，非必需）：

```bash
cd web-app/demo && python -m http.server 5173
# 打开 http://localhost:5173/index.html
```

### 跨页状态

- 采用的设计写入 `localStorage`（键 `sv_refboard` / `sv_task`），刷新与跳转后仍在。
- 首次打开 create.html 会放入 2 条**示例**参考，方便直接看到参考板效果；一旦增删就以你的真实选择为准。
- 右下角固定丝带 `DEMO · 示例数据 · 非实时`。

## 自检脚本

两个脚本都**不额外安装依赖**——复用 copycat skill 自带的 Playwright：

```bash
cd ~/.dsh/skills/copycat/scripts
node /d/App/web-app/demo/shot.mjs       # 截图 + 控制台错误 + 横向溢出检查
node /d/App/web-app/demo/interact.mjs   # 交互回归：参考板跨页 / 视图切换 / 引用链 / 轮播
```

`shot.mjs` 输出桌面视口图、桌面全页图、素材视图全页、移动端全页，并打印控制台错误数与 `scrollWidth`（与视口相等即无横向溢出）。

`interact.mjs` 覆盖的断言：首页「采用这个设计」→ 计数递增；一句话任务跳转创作页后任务与参考都带过去；参考可移除；候选方向单选；脚本视图 ↔ 素材视图列切换；引用链展开/收起；轮播滚动。

**当前结果：两页控制台错误 0，桌面/移动均无横向溢出，交互断言全部通过。**

## 已知限制（有意为之，不是 bug）

- **未制作页面**：热点抓取、热点分析、素材库、更新中心——点进去只弹 toast 说明「演示页面未制作」。站点树见 `docs/sitemap/网站地图 v1 草稿.md`。
- **展示字体**：得意黑（Smiley Sans）无法从 Google Fonts 稳定获取，hero 大标题暂用 Noto Sans SC 900 + 紧排替代；正式构建时应自托管字体文件（OFL 授权）。楷体（LXGW WenKai）用于「人的话」引语，等宽（JetBrains Mono）用于标签。
- **数据全部是示例**：封面用渐变色块占位（真实封面走素材库授权图）；达人已标「主页待核实」徽章。
- **无后端**：没有真实抓取、存储、鉴权；localStorage 只做跨页传递演示。
- 版权边界：Givingli 截图仅内部参考，不进交付物（见 `docs/design/DESIGN_SYSTEM v1.md` 版权章节）。
